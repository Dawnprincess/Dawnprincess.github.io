链表

基础知识

链表是一种通过指针串联在一起的线性结构，每一个节点由两部分组成，一个是数据域一个是指针域（存放指向下一个节点的指针），最后一个节点的指针域指向null（空指针的意思）。

链表的入口节点称为链表的头结点也就是head。

链表类型有单链表，循环链表，双向链表。

在C++中这样定义

链表在插入，删除O(1)操作上，但是查询要慢O(n)。而数组插入删除需要O(n)，查询要O(1)。

链表常常要借助前一个节点对当前节点进行操作，这就造成头结点head没有前一个节点需要特殊处理的情况，而引入dummyNode虚节点可以将头结点一视同仁，简化操作逻辑。

例题

1.删除元素

203. 移除链表元素 - 力扣（LeetCode）

因为链表头结点的特殊性（根据前一个节点的next删除下一个，而头结点没有前一个节点）删除链表元素一般有两种方式，一个是对头结点单独处理，另一个是设置虚节点，然后一视同仁。

2.反转链表

206. 反转链表

反转方法可以考虑双指针法（或者添加虚节点，使用头插法），需要注意的是，从头开始遍历是，一定要从head开始（而不能从head->next开始，这样需要添加检查head->next是否为空使代码变得复杂，如下对比），很明显后者更加简洁一般。

而由此还可以将迭代的方法改为递归，递归初始化和迭代一样，都是将pre设置为null，出口即为while判断的条件，cur==null时，返回pre，递归的操作内容即为while内容，但是pre = temp和cur = cur->next由递归函数的更新代替，仅仅将cur的next指向pre即可。

当然上述方式实际上都是从头开始反转，如果考虑递归的话，更多想到的是从尾开始递归，想法即要反转head->next指向，通过递归函数将head->next后续的链表都反转即可

4.删除倒数第n个元素

19. 删除链表的倒数第 N 个结点 - 力扣（LeetCode）

常规想法不说了，遍历一遍，查出来倒数n，然后再遍历删掉。这里使用双指针可以遍历一次完成，简单说就是将fast指针先移动n，然后slow和fast同时移动，当fast结束时，slow即为要删除的元素（妙哉妙哉）。

5.链表相交

面试题 02.07. 链表相交 - 力扣（LeetCode）

给出的两个链表只可能会在最末尾连着相交（使用同一块内存，数据相同），找从哪里开始相交。

因为只可能在最后的几个元素共用，所以前面的可以忽略，需要忽略多少，这取决于两个链表的长度之差gap，至少长链表前gap个元素是不会与短链表相交的（否则不可能相差gap个元素）。采用双指针，fast从长链表开始，先遍历gap个元素，这时和slow两者到链表末尾的距离相同，依次对比即可。

实现方面，用?:三元运算符寻找较长较短极为便捷。

6.环形链表

142. 环形链表 II - 力扣（LeetCode）

给出一个找环形链表的方法，一个快指针，一个慢指针，如果是环形两者总能相遇（环形跑道）。

那么如何找到环的入口在哪？两者能相遇，一定在环内相遇，并且一定是慢指针还没走完一圈就相遇（这可以简单证明），而快指针可能已经走很多圈。

相遇时： slow指针走过的节点数为: x + y， fast指针走过的节点数：x + y + n (y + z)，n为fast指针在环内走了n圈才遇到slow指针， （y+z）为 一圈内节点的个数A。

求环的入口即为求x的长度，x = (n - 1) (y + z) + z。

n为1时，x=z，即入口长度和相遇时离入口的长度相同。当n>1时，x=环长度+相遇时距离入口的长度

这一部分求解可以在快慢指针相遇时，另设两个指针，从头和相遇点同时开始遍历，直到两者相遇即为入口点。
