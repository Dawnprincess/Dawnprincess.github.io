课程

一、虚拟内存核心：为什么引入

核心目的：进程地址空间隔离，避免进程相互干扰、越权访问内存。
硬件支撑：CPU + MMU（内存管理单元），通过页表完成虚拟地址（VA）→ 物理地址（PA）转换。
关键寄存器：satp 存放页目录基地址，MMU 据此找到页表。

二、单级页表（问题）

64 位系统：低 12 位为页内偏移（固定 4KB 页），高 27 位为页表索引。
项数：2^27 个页表项（PTE），每项 8 字节 → 总大小 2^29 字节（512MB）。
致命问题：单进程页表体积巨大，且要求连续物理内存，系统无法承载多进程。

三、多级页表（解决方案）

  1. 设计思路
    将高 27 位拆分为 3 个 9 位，对应三级页表，每级索引 512 项（2^9）。
    只有实际使用的页才分配页表，大幅节省内存。
    用 PTE_V（有效位）标记未使用的 PTE，可直接清理。
  2. 核心函数：walk（kernel/vm.c）
    pte_t *walk(pagetable_t pagetable, uint64 va, int alloc);
    功能：三级页表查询，返回 VA 对应的最低层 PTE。
    逻辑：
    检查 VA 合法性（< MAXVA）。
    逐级查 PTE：有效则取下一级页表；无效则按 alloc 决定是否分配新页。
    最终返回末级 PTE 指针。
  3. 地址转换宏
    PTE2PA(pte)：PTE → 物理地址（右移 10 位清标志位，左移 12 位补页内偏移）。
    PA2PTE(pa)：物理地址 → PTE。
    PX(level, va)：取 VA 在某级页表的索引（0~511）。

四、xv6 内存布局

  1. 物理内存（memlayout.h）

#define KERNBASE 0x80000000L // 内核起始物理地址
#define PHYSTOP (KERNBASE + 12810241024) // 物理内存上限
QEMU 模拟 RAM 从 0x80000000 开始。
低地址：CLINT、PLIC、UART、Virtio 等设备寄存器。
0x80000000 起：内核代码（text）、数据（data）、空闲内存。
2. 虚拟内存空间
内核空间：KERNBASE（0x80000000）以上。
用户空间：0 ~ KERNBASE。
高地址特殊页（最高位）：
TRAMPOLINE：跳板页，内核↔用户态切换，最高虚拟地址。
TRAPFRAME：中断帧，保存系统调用 / 中断时的寄存器与 PC。
内核栈：带守护页（guard page），防止栈溢出踩踏。
3. 用户进程地址空间布局
0 → text(指令) → data/bss(全局变量) → stack(固定栈) → heap(动态扩展)
→ … → TRAPFRAME → TRAMPOLINE(最高地址)

五、关键页与机制

TRAMPOLINE
内核与用户空间共享同一物理页。无 PTE_U，仅特权态可执行。
TRAPFRAME
每个进程独有，保存用户上下文。
权限：PTE_R | PTE_W。
守护页（Guard Page）
无效映射页，栈溢出触发缺页异常，防止内存破坏。

六、页表创建与映射（实验：USYSCALL 共享页）

  1. 进程页表创建（proc_pagetable）
    流程：创建空页表 → 映射 TRAMPOLINE → 映射 TRAPFRAME → 映射 USYSCALL 共享页。
    // 映射用户态可访问的共享页
    mappages(pagetable, USYSCALL, PGSIZE,
    (uint64)(p->usyscall), PTE_R | PTE_U);

必须加 PTE_U：允许用户态访问。
映射失败需回滚已映射页，避免内存泄漏。
2. 内存分配与释放
分配：allocproc 中分配 usyscall 物理页。
释放：freeproc 用 kfree 释放；proc_freepagetable 用 uvmunmap 解除映射。

七、内核→用户数据拷贝：copyout

int copyout(pagetable_t pagetable, uint64 dstva, char *src, uint64 len);
功能：内核态数据 → 用户态虚拟地址。
关键步骤：
PGROUNDDOWN(dstva)：VA 按页对齐，取页起始地址。
walkaddr：查对应物理地址 PA。
按页内偏移 memmove 拷贝数据。

八、QEMU 查看内存映射

QEMU 控制台执行
info mem
0x80000000 以下：内核空间映射。
0x80000000 以上：用户空间映射。
高地址 0x3fffffb000/0x3ffffff000：TRAPFRAME / TRAMPOLINE。
