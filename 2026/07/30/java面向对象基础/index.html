java基础

Java重要特点

1.Java语言是面向对象的（oop）
2.Java语言是健壮的。Java的强类型机制、异常处理、垃圾的自动收集等是Java程序健壮性的重要保证
3.Java语言是跨平台性的。［即：一个编译好的.class文件可以在多个系统下运行，这种特性称为跨平台
4.Java语言是解释型的。区别是：解释性语言，编译后的代码，不能直接被机器执行，需要解释器来执行，编译性语言，编译后的代码，可以直接被机器执行例如c/c++

关键概念

1.什么是 JDK、JRE
JDK 的全称 (Java Development Kit Java 开发工具包)
JDK = JRE + java 的开发工具 [java, javac,javadoc,javap 等]
JDK 是提供给 Java 开发人员使用的，其中包含了 java 的开发工具，也包括了 JRE
所以安装了 JDK，就不用在单独安装 JRE 了。
JRE (Java Runtime Environment Java 运行环境)
JRE = JVM + Java 的核心类库 [类]
包括 Java 虚拟机 (JVM Java Virtual Machine) 和 Java 程序所需的核心类库等，
如果想要运行一个开发好的 Java 程序，计算机中只需要安装 JRE 即可。

2.javac即java编译器，java源文件通过javac编译生成class字节码文件，class文件可以放在jvm虚拟机中运行（通过java.exe运行.class文件）。每一个类对应一个class文件。

3.java源文件名必须和其中的public类名一致（意味着一个java源文件只能有一个Public类）

代码规范

1.类、方法的注释采用javadoc的风格注释
2.非javadoc的注释给代码维护阅读的人看
3.源文件编码常采用utf-8，而不是gbk

基础知识

数据类型

1.浮点数默认double类型，整数默认int类型。
注意：小心对小数运算的结果进行比较，例如8.1/3结果并不是2.7。而是以差值结果在某个精度内来比较。

2.字符型char,采用unicode编码
对比c语言的char类型，采用的ASCII码，128个字符（实际上8位可以表示256）

3.转换
自动转换：精度小的可以自动转化为精度大的类型，例如int + double结果是double。
反之精度大的不能转为精度小的。

强制转换：精度大的数据向精度小的转换，可能有精度降低或者溢出的情况。

4.数组
数组变量指向的是一个地址，而不是具体的数组值，进一步二维数组指向的也是二维数组的地址，其中保存的是一维数组的地址。
值拷贝（值传递）和地址拷贝（引用传递），即数组赋值arr1 = arr2，是将arr2所指的数组地址给了arr1

面向对象编程

1.jvm内存分布：
堆：new创建的对象本体都在这;垃圾回收GC（管理对象生命周期）在这里工作;所有线程共享这块内存。
栈：方法里的局部变量，对象的引用地址，方法的返回地址（执行完去哪）；线程私有，用完销毁。
方法区：类的结构信息（字段，方法，构造器等），静态变量，常量，常量池；线程共享。
(在JDK1.8之前，字符串常量放在方法区，后续转移到堆区)
例子
public class Dog{
String name = “旺财”;//堆
static String sex = “公”;//方法区
static void main(){
int a = 1;//栈里
…
}
}
dog1 = new Dog();//dog1在栈里，dog1指向的对象在堆里

2.new会创建好一个实例，并返回该实例的地址
3.方法调用：
当程序执行到方法时，开辟一个独立于原方法的空间（栈）
执行完毕或者到return时返回，返回到调用方法的地方（同时销毁该栈）
继续执行方法后面的代码
main方法执行后，程序退出
4.方法传参
对于基本数据类型变量，在作为参数传给方法时，实际上是在方法新栈里保存的是复制的一份。
对于引用数据类型（如数组，对象等），作为参数传给方法时，方法栈里保存的地址是指向了同一块数据存放区域。

5.重载
两个条件，方法名一样，参数类型或顺序不一样
可变参数

6.作用域
全局变量：即属性，作用域为整个类。可以不赋值，有默认值。可以跨类试用
局部变量：在成员方法中定义的变量。必须赋值后才能使用。只能在本类对应的方法中使用
属性和局部变量可以重名，使用时就近原则。

7.对象的创建流程
首先加载对象信息到方法区
在堆中分配相应空间，进行初始化
默认初始化
显式初始化
构造初始化
返回该对象在堆中的地址

构造器中可以调用其他构造器（可以通过this()调用构造器）

8.修饰词
public:公开，对所有
protected:对该包内其他类和子类公开（不同包不能访问）
默认:对包内其他类公开
private:仅该类
从上到下，依次关闭其他包，子类，同包的访问
类只有public和默认两种修饰，类的属性、成员方法可以由上述四种修饰。

9.面向对象编程的特点
（1）封装（encapsulation），对内部细节进行隐藏
私有化属性，公共set（合理性校验）,get方法（权限校验）
（2）继承（extend）
I.子类继承所有属性和方法，但是无法直接访问私有属性，可以通过公共方法访问。
II.子类创建时，一定会先创建父类（即默认会调用父类的构造器即super()（与this()不共存），默认为无参构造，若无无参构造器，则必须通过向super传参去指定特定的构造器）
III.Object是所有类的父类
IV.java中子类最多继承一个父类（单继承），那么如何让A继承B和C类？让B和C继承，然后A再继承
V.满足“子类 is a 父类”可以使用继承
VI.继承在内存中的关系

子类会继承父类的所有属性（即使不可访问，即使子类覆盖），在堆中给出空间

super:代表对父类的引用（相当于this对自身的引用），super()相当于this()调用构造器。super对父类的访问不局限于直接的父类，例如super.a，如果父类找不到a，会继续向上一直找（除非中间有private等限制会停下）

方法重写（覆盖override）:子类的方法名称，返回类型（或者其子类）和参数和父类一样；重写的方法不能缩小原方法的权限比如public重写后变成protected

（3）多态（polymorphism）

问题：一个人养了多种动物，每种动物吃不同的食物，由此需要给人写多个不同但很相似的feed方法。

public void feed(Dog dog, Bone bone){
  给小狗喂骨头;
}
public void feed(Cat cat, Fish fish){
  给小猫喂鱼;
}
...

重写和重载都体现了多态的思想。
多态的核心：
  （1）一个对象的编译类型和运行类型可以不一致。
  （2）编译类型在定义时确定，不可变化，而运行类型时可以变化的。
  （3）编译类型看=左侧，运行类型看右侧

可以将上述的feed方法合并
public void feed(Animal animal, Food food){
  给 animal 喂 food;
}
当后续再添加新的动物，食物时，feed方法不需要改变
父类的引用可以指向子类，利用这，调用时
Animal animal
 = new Dog();
animal.cry();
就转到了dog对应的cry里面，可以调用父类中的所有成员，不能调用子类的特有成员。
例如cat可以catchMouse()，不可以有animal.catchMouse()。

I.这些就是向上转型：
  1.可以调用父类所有成员
  2.不能调用子类特有成员。因为编译时，编译器就看这个方法在这个类及其父类里面有没有，有就可以通过编译。
  3.但具体运行时调用哪个方法，看是谁在运行调用谁的方法。（从子类开始查找，调用具体方法）
  ⭐关键是父类引用指向子类

II.那如果就想调用子类的特殊方法怎么办？可以向下转型
  子类类型 引用名 = (子类类型)父类引用
  ⭐强制转换父类引用，将其指向子类（并不可以转换父类本身对象）。
  例如

Cat cat = (Cat)animal;
cat.catchMouse();

但之后不能指向其他子类了
cat = new Dog();❌️

简单来说，向上转型就是找一个用一个更大范围的引用指向一个小范围，向下转型就是把这个大范围引用缩小一点。
Animal animal = new Cat();//向上
Cat cat = (Cat)animal;//向下

III.对于属性来说，没有重写一说，⭐对应的值就看其编译类型（因为属性的值在编译期就已经决定，而具体的方法到底调用哪个需要等到运行期才绑定），
cat.name就看cat对应的name

instanceOf可以用来比较该对象的运行类型是否为XX或其子类
可以利用这个机制，判定父类实际指向的对象类型，来通过向下转换（将父类引用指向子类）调用子类特定对象方法

这也就是⭐动态绑定机制
即调用对象方法时，该方法会和该对象内存地址/运行类型绑定（运行时决定）
而调用对象属性时，没有动态绑定，哪里声明就在哪里使用

应用，方法参数多态，形参为父类，实参为子类

JDK源码

1.Object类:
  I. ==既能判断基本类型（内容是否一样），又能判断引用类型是否相同（⭐指同一个对象），
    Object类中的equal()方法默认只判断引用类型（地址一样与否），⭐但子类往往会改写这个方法，来判断内容是否相等，例如下面的String里的equals

2.hashCode()
hashCode()可以返回对象的哈希值，提高具有哈希结构容器的效率。
哈希值由地址映射，因此可以一定程度上表示地址，但不是地址。
两个引用指向同一个对象，哈希值一定相同，如果不同，则一定不一样。

3.toString()
Object中的toString可以返回“包名+类名@哈希值”，即getClass().getName() + "@" + toHexString(hashCode())
子类重写通常用于显示对象属性值，直接打印对象也调用该方法

4.finalize
当对象被回收时，系统会自动调用该对象的finalize方法，来释放资源。
当对象没有任何引用时，jvm就认为这是一个垃圾对象，会使用垃圾回收机制来销毁对象，在销毁对象前，会先调用finalize（但并不是对象没有引用就立即销毁，而是由jvm的GC垃圾回收算法来决定何时调用）。
子类可以重写该方法决定释放资源。
